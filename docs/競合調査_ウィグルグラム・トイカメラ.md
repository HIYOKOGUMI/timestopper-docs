# 競合調査：多眼ウィグル・トイカメラ

- 作成日: 2026-06-03
- 対象プロダクト構想: 小型カメラ(レンズ)を **横一列に4〜5個** 並べ、シャッターで **同時撮影** → 0.5〜1秒で連続再生し、被写体が横に一瞬ずれて見える写真(=**ウィグルグラム / wigglegram**)を撮る、**チープなキーホルダー的トイカメラ**
- 想定第一市場: **日本**
- ステータス: 初期リサーチ＋**日本クラファン＋海外クラファン＋OEM(Alibaba)の確認まで完了**(2026-06-03)。残るは K4MERA の継続ウォッチ等の定点観測のみ。

---

## 0. 用語
- **ウィグルグラム(Wigglegram / wiggle 3D)**: 複数レンズで視差のある複数枚を同時撮影し、高速に行き来再生して疑似3D・「ぐにゃっと動く」効果を出す手法。原理は19世紀のステレオ写真まで遡る公知技術。
- **バレットタイム(Bullet Time)**: マトリックスの「時間が止まったまま視点が一周」する技法。被写体を囲む25〜150台のカメラで実現。ウィグルとは規模が別物。

---

## 1. 結論(エグゼクティブサマリー)

1. **ユーザー構想のアイデア自体は新しくない。** 多眼ウィグルはトイ/DIYの定番ジャンル。
2. ただし **3条件すべて(①デジタル ②多眼ウィグル ③チープな単体トイ/キーホルダー型)を満たす量産品は現状存在しない** → 市場の空白＝勝ち筋。
3. **最も近い直接競合は K4MERA**(4眼デジタルウィグル/スイス/**未発売**)。ただし高機能・高価格路線で、ユーザーの「チープなトイ」とは層がズレる。さらに **日本未流通**。
4. **価格面の脅威は Pocket Dispo Parallax**($49.99・3眼デジタル・日本へ国際送料無料)。ただし **レンズ装着型**で単体カメラではない。
5. 日本市場で実際に警戒すべきは **RETO 3D(ウィグル唯一・日本正規流通)** と **ドンキ等の激安キーホルダー型トイデジ(ただし1眼)**。
6. **米国の強豪トイデジ(Camp Snap 等)は日本でほぼ流通せず、日本での直接競合にならない**(ユーザーの読み通り)。

### 空白の確認
3条件すべてを満たす製品は無い:
- K4MERA → ③が逆(高機能・高価)＋未発売

→ **「デジタル × 多眼ウィグル × トイ価格の単体機 × 日本流通」は依然空白。**

## 3. ポジショニングと差別化方針

```
       高機能・高価格
            ↑
   K4MERA(4眼デジタル/スイス/未発売)   QooCam EGO(2眼立体/$369)
            │
 RETO 3D(3眼フィルム/日本流通あり)   Pocket Dispo Parallax(3眼デジ/レンズ型/$49.99)
            │
 ─── 狙い目の空白 ────────────────────────────
   「4-5眼デジタル × キーホルダー的チープさ × 即GIF × 日本発」
            │
 ドンキ/3COINS(1眼トイデジ・激安・日本)
            ↓
       低機能・低価格
```

- **対 K4MERA**: 相手は高機能・高価・未発売。こちらは「安い・軽い・キーホルダー・即SNS」。機能で competeしない。**スピード**(相手が出る前に日本で先行)も鍵。
- **対 RETO 3D**: 相手はフィルム(ランニングコスト・現像必要)。こちらは「撮ってすぐGIF・SNS即投稿」で層をずらす。
- **対 ドンキ/激安トイデジ**: 相手は1眼"エモ写真"。こちらは「動く写真(ウィグル)」で機能的に別物。
- **販路の盲点**: 米強豪が手薄な日本で先行。海外展開時は K4MERA / RETO 3D に注意。

## 4. 特許・知財メモ
- **基本原理(多眼で視差撮影＋連続再生)は公知**で独占されていない。
- 特許が押さえるのは具体的実装(同期制御・画像処理パイプライン・装置構成)。
  - バレットタイム: Dayton Taylor "Timetrack" → **US6154251A**(2000成立)。新しめに **US10051170B2 / US20170208238A1**、中国 **CN205901882U / CN111479036A**。
- **個人製作の侵害リスクは低い。** 販売時は同期回路・合成アルゴリズム等の実装について弁理士の先行特許調査を推奨。

## 5. 技術メモ(自作の現実解)
- Raspberry Pi Camera / ESP32-CAM 等の小型モジュールを4〜5個横並び。
- GPIO/トリガーで **同時シャッター(同期発火)**。
- 撮影画像を **被写体中心に位置合わせ(レジストレーション)** → GIF/動画化。
- 画質の肝: **同期精度**と**レンズ間レジストレーション**。

## 5-B. 日本クラファン/国内市場の確認(2026-06-03 追記)

**結論：日本のクラファン・国内市場に「デジタル多眼ウィグル・トイカメラ」の先行者は無し。空白は確定的。**

### Makuake(マクアケ)
- ウィグル系は **RETO 3D のみ**。ただし**3眼フィルム・海外製品の日本上陸版**(`reto3djapan`、クラファン価格 約¥17,800)。現像→スキャン→アプリ合成の手間あり。
- 他の「3D」案件は畑違い:**3Dスキャナー**(3DMakerpro Eagle / Creality / Revopoint)、**裸眼3Dフォトフレーム**(JOYHONG)。多眼で写真を撮るデジタルウィグルカメラはゼロ。

### GREEN FUNDING
- **「SID」(Weeview製)** = コンパクト**3D"動画"カメラ**(ステレオ動画)。ウィグルでもトイでもない別カテゴリ。

### CAMPFIRE
- **1眼トイカメラ**のみ(800万画素手のひらカメラ、子供向けDegi-TOY等)。多眼ウィグルは無し。

### 国内メーカー新製品(参考・すべて1眼/非ウィグル)
- タカラトミー「FUNSHOT」(2025-10発売)、アガツマ アンパンマン キッズカメラ、Kenko Pieni II。

### 方法上の限界(正直なメモ)
- Makuake/CAMPFIRE の**サイト内検索ページは JS描画/ログイン制**で WebFetch では中身取得不可(調査中に HTTP 404/空応答が発生)。よって「**現在公開中の小規模プロジェクト**」の100%網羅は未達。
- ただしGoogle横断検索で国産デジタルウィグルは一切浮上せず。実在すれば通常は記事化・SNS拡散されるため、空白の可能性は高いと判断。**完全網羅には両サイトへ会員ログインして内部検索が必要。**

## 5-C. 海外クラファン/OEM完成品の確認(2026-06-03 追記)

**結論：海外クラファン(Kickstarter/Indiegogo)にもAlibabaにも「単体のデジタル多眼ウィグル・トイカメラ」は存在しない。空白は世界的に確定。**

### Kickstarter / Indiegogo(直近〜進行中)
- **Kitslo** … iPhone用ウィグルレンズ。2025年1〜2月に **$9,814 / 118 backers** で成功。→ **レンズ装着型**(単体カメラでない)。
- **George Moua「New Niveau」44mm Trioscopic 3D Wiggle Lens** … ミラーレス用(Canon RF/Nikon Z/Sony E)。→ **レンズ単体**。
- **K4MERA** … 依然 waitlist(未発売)。
- **RETO3D「Wiggle The Moment」**(Indiegogo) … **フィルムカメラ**。
- → 単体デジタル機は K4MERA のみ、他は全部「レンズ」か「フィルム」。**トイ価格の単体デジタルは皆無。**

### Alibaba(OEM完成品の有無=参入障壁チェック)
- 出てくるのは **3Dカメラ"モジュール"**(ステレオ/構造化光の深度センサ。$335〜435、機械視覚・深度用途)と、**1眼ミニカメラのOEM/ODM**(スパイカメラ系)が大量。
- **「多眼ウィグルのトイカメラ完成品」は見当たらず。**
- 両面の意味:
  - ✅ **良い面**: 白ラベルで安く真似できる既製品が無い = **模倣参入の障壁が現状ある**。
  - ⚠️ **注意面**: そのまま転売/OEMできる完成品も無い = **自前でカスタム開発が必要**(モジュール調達＋同期＋合成を自社で作り込む)。
