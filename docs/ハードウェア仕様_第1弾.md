## 0. 一行サマリー

**4眼・横一列のESP32ベース・デジタルウィグル・トイカメラ。静止〜超低速被写体に割り切り、撮り溜め→Wi-Fi一括転送→スマホアプリで合成。レトロな光らない液晶＋コールドシュー拡張、FDM 3Dプリンタ筐体。推定BOM ≈ $30前後。**

---

## 1. 設計の根：同期グレード

- **採用 = 静止〜超低速のみ**（人がポーズして静止／置物／風景）。
- 露光ズレ数〜数十msを許容。**命令ベース同期＋撮影後ソフト位置合わせ**で成立。
- 動体（歩く・走る・乗り物）をピタッと止める路線は、グローバルシャッター級が必要でトイ価格と両立不能なため**狙わない**。
- 競合の空白＝「動体停止の高性能」ではなく「**チープなのにデジタルで動く写真が撮れる**」体験そのもの。ここに投資を集中。
- 注意：静止路線でも「手ブレ」「被写体の微動」は残る → **撮影ガイド（“1秒止まって”表示）＋ソフト位置合わせの質**でチープに見せない。

## 3. 各枝の根拠と詳細

### 3.1 眼数：4眼

- 横一列4眼。なめらかさで「視点が流れる」感が明確に出る最小寄りの構成。Hackaday先行事例も4眼で参考設計が最も揃う。
- 3眼（最小成立）より体験が一段上。5眼は幅・原価・同期負荷が過大でキーホルダーに不向き。

### 3.2 駆動方式：ESP32チップ×4・同一ファーム

- **重要な技術前提**：ESP32/S2/S3のDVP（パラレル）カメラI/Fは内部でI2Sを間借りしており**1ポートのみ＝複数カメラを多重化できない**（Espressif明言）。よって素のOV2640(DVP)は**カメラ1個につきMCU1個**が必要。
- 「1個のESP32で4カメラ」を成立させるにはSPI-FIFOカメラ（ArduCAM系：オンボードFIFO＋ArduChip）が必要だが、**FIFO＋専用コントローラがMCU1個より割高**で、サイズ削減効果もカスタムSMT基板では出ない → トイ価格では不利。
- 結論：**素のOV2640×4＋安いESP32チップ×4・同一ファーム**（うち1個がマスター、シリアルトリガで同時撮影命令）が最安かつ部品共通で素直。
- **量産コスト削減の再検討候補**：マスターESP32（WiFi/処理）＋RP2040スレーブ×3（各カメラ撮影）。RP2040(~$1)でMCU費を圧縮できるが、公式ドライバ非対応で自前実装寄り＋ファーム不均質化のため、節約幅(~$4)に対し開発リスクが大きい → 第2弾フェーズで検討。

#### サイズ・原価の比較（量産1,000台規模・ざっくりUSD）

| 項目 | (採用) ESP32×4＋素OV2640 | (不採用) ESP32×1＋SPI-FIFO×4 |
|---|---|---|
| センサ ×4 | 約$12 | 約$12 |
| 頭脳 | ESP32 約$2×4 = $8 | ESP32×1 = $2.5 |
| FIFO/コントローラ | 不要 $0 | 各カメラに必要 +$25〜50 |
| 電源/SD/電池/ボタン/筐体/PCB | 約$10 | 約$10 |
| **BOM合計** | **約$30** | **約$50〜75** |

- レンズ4個は両案共通で本体幅を支配（約55〜65mm）。基板サイズも両案ほぼ同等 → **「1 ESP32だから小さい」は ESP32-CAM開発ボード4枚と比べた場合のみ**で、カスタムSMTでは差が出ない。

### 3.3 画像処理：本番はスマホアプリ

- 4枚の位置合わせ→GIF/MP4エンコード→SNS共有は**スマホのCPU/GPUが圧倒的に有利**。本体から液晶（プレビュー用）も省け、コスト/サイズ/電力を最大級に削減。
- 本体は「4枚の生JPEGを撮ってmicroSDに溜める」に専念。
- **実証課題（別トラック）**：本体内処理(ESP32-S3@240MHz/PSRAM 8MB)がどこまで可能か。見立て＝フル解像度は厳しく、640×480へ縮小→単純相関で位置合わせ→数枚GIF化で**480p級プレビューが数秒**なら成立見込み。**合否基準＝「480pウィグルGIFを本体単体で◯秒以内に生成できるか」**。満たせば「単体プレビュー＋本番アプリ」のハイブリッド余地。

### 3.4 転送/保存：Wi-Fi一括転送＋microSD撮り溜め

- 運用：**microSDにどんどん撮り溜め → 後でまとめてWi-Fiで一気にアプリへ転送**。
- 即時1枚送り前提が外れる → 本体に液晶/プレビューはより一層不要、Wi-Fiは「転送時だけ親APを立てる」運用で電力も楽。
- BLEは帯域不足（4枚で数秒〜十数秒）で「すぐ見られる」体験を損なうため不採用。
- 保存構造：1撮影＝連番4ファイル（例 `WG000123_1.jpg`〜`_4.jpg`、左→右順固定）＋セットのメタ（撮影時刻・モード・眼順）を軽量インデックス(JSON/CSV)でSD保持。アプリは一括転送時にこれを読んで束ね直し＆**未転送セットだけ差分DL**。

### 3.5 光学：15mmピッチ・35mm相当・固定焦点

- レンズ間ピッチ約15mm（4眼で両端基線長45mm）。本体幅約50〜60mm。実写で最終決定（仮15mm）。
- **OV2640(1/4型・有効約3.59×2.71mm・対角約4.5mm)** に対しクロップ係数約9.6× → **35mm判換算35mmは実焦点約3.6mmのレンズ**。標準画角帯で広く流通・安価・特殊光学不要。
- 固定焦点パンフォーカス（AF無し＝コスト/サイズ/故障減）。中画角約63°。
- **視差サニティチェック**：被写体0.5mで視差角約5.1°（強め）、1.5mで約1.7°（自然）。**手元〜2m・背景に奥行きのある被写体**が最も気持ちよく動く。
- **品質の肝**：4眼を**同一ロット・同一画角・同一焦点**で揃え画角公差を最小化（ガタつき防止）。

### 3.6 解像度：標準SVGA／上位UXGA

- 標準 SVGA(800×600) JPEG中品質（1枚~60〜100KB、1セット~300〜400KB）。SNS向けウィグル(480〜720p)に十分で、撮り溜め・一括転送が軽快。
- 上位モデル or 設定切替で UXGA(1600×1200) を開放（高画質/トリミング耐性ニーズ向け）。

### 3.7 電源：LiPo＋USB-C

- 内蔵LiPo 約400mAh（SVGA運用で数十〜百数十セット撮影＋1回の一括Wi-Fi転送を狙い、実測で確定）。
- USB-Cを充電＋（保険の）有線吸い出し＋ファーム書き込みに兼用。
- ⚠️ **法務波及**：LiPo内蔵は日本の**PSE（電気用品安全法）対象**判定・**リチウム電池の輸送/輸入規制**・**保護回路（過充電/過放電）のBOM追加**が必須。法務枝で要確認。

### 3.8 操作・表示

- **ボタン2個**：電源・シャッター。電源ボタンは長押しON/OFFに加え、**長押し/ダブルクリックでWi-Fi一括転送開始・モード切替を兼用**（ボタンを増やさない）。
- **ブザー/スピーカー**で「カシャ」音（トイの満足感の核、安価）。
- **表示はステータス専用**（電池残量・撮影セット数・SD空き・Wi-Fi転送状況・モード）。**ライブビューは出さない**（ESP32負荷・電力・粗いモノクロでの低精度を回避。上位モデル送り）。
  - **標準モデル：PCD8544(84×48)反射ドット液晶**。バックライト無し＝「光らないレトロ」、文字/アイコン自由表示、型代不要・$2〜4・SPI接続。明所で読む/暗所は読みにくいのはレトロの味として許容。
  - **上位モデル：SSD1306 0.96型モノクロOLED**（自発光・暗所可）。
  - ファームは表示ドライバを抽象化し2機種を吸収（どちらもSPI/I2Cで軽い）。

### 3.9 ストレージ

- microSDスロット内蔵（最大32GB・FAT32・SDHC＝ESP32の鉄板）。出荷時カード同梱なし。
- **購入時オプションでSDカード付き構成**も選べるようにする。
- 内蔵フラッシュ(カードレス)案は容量固定・コスト増・寿命管理で不採用。

### 3.10 形状・装着

- 横長バー型キーホルダー。部品逆算で **約60×48×18mm／約50g**（マッチ箱より少し大きい“ぽってりキーホルダー”）。
- ストラップ穴/リングで装着。**三脚穴は付けず、コールドシュー（機械式）で拡張性**を持たせる。三脚はシュー→1/4"変換アダプタで対応可能。
- 電気接点付きホットシューは防塵・規格整合・コスト増で第1弾は不採用 → 将来/上位で検討。
- 内蔵フラッシュなし（光が欲しければシューに外部ライト）。非防水（コスト優先）。

### 3.11 筐体製法：FDM 3Dプリンタ

- 本番設計=Fusion 360、デモ機=Tinkercad。ユーザーはFDM機所有・経験あり。
- **材料**：デモ/Tinkercad造形はPLAでOK。ただし**機能機（LiPo内蔵・高温環境）はPLA非推奨**（~50〜60℃軟化）→ **PETG/ASA/ABS**推奨（屋外トイならUV耐性のASA）。
- **組立**：**真鍮ヒートインサート＋ビス**で分解可能に（電池・SD・基板保守）。スナップフィットは割れやすく非推奨。
- **★4眼レンズ位置精度**：ウィグル品質＝4眼が正確に15mmピッチ・同一平面・同一向き。FDM公差±0.2〜0.3mmがズレると「安物のガタつき」に直結 → **カメラモジュール位置決めの一体プリント治具/リブ＋座面ピン**を筐体に作り込む。レンズ前面穴は印刷後にリーマ/座ぐり仕上げ前提で公差を持たせる。
- **コールドシュー**：プリント製は強度不足 → **金属シューを埋め込み（インサート）**。

- **量産スケール方針（要決定）**：
  - (A) FDMは試作・デモ・クラファン初期ロットまで → 量産は射出成形（金型）に移行。設計は最初から射出成形（抜き勾配・肉厚）を見据える。【推奨・段階戦略】
