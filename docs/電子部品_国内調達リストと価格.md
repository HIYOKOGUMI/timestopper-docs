## 0. 調達戦略の二層構造

| フェーズ | 調達先 | 狙い |
|---|---|---|
| **試作・デモ・クラファン初期** | 日本国内（秋月電子・スイッチサイエンス・aitendo・Amazon.co.jp 等） | すぐ手に入る・少量・確実。本ドキュメントの主対象 |
| **量産（1,000台〜）** | 中国OEM/Alibaba・LCSC でバルク調達 | 素のOV2640やESP32チップを単価ベースで。BOM ~$30(約¥4,500)へ（§4） |

> 試作は「**ESP32-CAM×4枚**」を核にするのが国内最安かつ最短。ESP32-CAMは **ESP32-WROOM＋OV2640＋microSDスロット**が1枚に載っており、Hackaday先行事例(4眼)もこの構成。仕様上の「ESP32チップ×4＋素のOV2640×4」は**量産時の最適化形**で、試作では既製のESP32-CAMで等価に検証できる。

## 4. 量産時のコスト見通し（参考）

`競合調査` の Alibaba/OEM 調査と整合。1,000台規模・SVGA構成での **BOM ≈ $30（約¥4,500）/台** が狙い：

| 項目 | 量産単価(目安) |
|---|---|
| OV2640センサ ×4 | 約$3×4 = $12 |
| ESP32(WROOMモジュールorチップdown) ×4 | 約$2×4 = $8 |
| LiPo/充電IC/microSDスロット/液晶/SW/ブザー/USB-C/PCB/コールドシュー 等 | 約$10 |
| **合計** | **≈ $30（約¥4,500）** |

- 国内バラ買い試作(約¥7,000〜14,000)に対し、**量産は半額以下**。これは「素のOV2640＋ESP32チップ＋自社基板」へ移行する前提（=ハード仕様書 §3.2 の駆動方式と一致）。
- 筐体はFDM試作 → 量産で射出成形に移行（仕様書 §4 未決事項）。

## 5. 発注前チェック・注意

- **LiPo**：航空便不可・**PSE（電気用品安全法）対象判定**と輸入/輸送規制を法務枝で要確認。保護回路(TP4056等)は必須。
- **OV2640の画角**：35mm判換算35mm相当＝実焦点 約3.6mm のレンズ個体を選定。ESP32-CAM標準添付レンズは広角寄り(120°等)のことが多く、**標準画角レンズへの差し替え or 選別**が必要な場合あり。
- **4眼の個体差**：レンズ・センサは**同一ロットで揃え画角公差を最小化**（位置合わせ品質＝製品の見栄えに直結）。
- 価格・在庫は2026年6月時点。秋月B0011のように**廃番**もあるため発注時に再確認。
