# ⏱️ TimeStopper ドキュメント

🐣 **HIYOKOGUMI（ひよこ組）** のプロジェクト **TimeStopper**（デジタル多眼ウィグル・トイカメラ構想）のドキュメントを、友達に共有しやすいよう1つのサイトにまとめたものです。

## 🌐 公開サイト（GitHub Pages）

**👉 https://hiyokogumi.github.io/timestopper-docs/**

左メニューまたはトップのカードから、各ドキュメントを1件ずつ開いて読めます。それぞれ独立したドキュメントで、末尾に「ここまで」の区切りが入ります。

## 📂 収録ドキュメント

| # | ドキュメント | 内容 |
| :-: | --- | --- |
| 1 | 製品コンセプト概要 | 第一弾モデルの製品像を確定した中核ドキュメント |
| 2 | OSS調査：ESP32 マルチカメラ同時シャッター | 同時シャッターの技術調査 |
| 3 | 競合調査：多眼ウィグル・トイカメラ | 競合・市場の調査 |
| 4 | ハードウェア仕様（第1弾） | 実機ハードの設計枝を確定したスナップショット |

ドキュメントの実体は [`docs/`](docs/) にある Markdown ファイルです。サイトはこれらをそのまま読み込んで表示しています。

## 🛠 構成

- `index.html` … サイト本体（サイドバー＋1ドキュメント1ビュー）
- `assets/style.css` / `assets/app.js` … デザインと表示ロジック
- `docs/*.md` … ドキュメント本体（編集すればサイトに即反映）
- `.nojekyll` … GitHub Pages の Jekyll 処理を無効化
